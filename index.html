JibonSetu — Blood Donation Platform

JibonSetu is a blood donation management platform designed to make it easier for people to find and connect with blood donors. It brings donor registration, blood donor search and blood-request management together in one place, with a user dashboard for managing activity.

Built with Firebase Authentication and Cloud Firestore, with Firebase Hosting for deployment. The project focuses on practical access to donor information while keeping user data protected through Firestore Security Rules.
